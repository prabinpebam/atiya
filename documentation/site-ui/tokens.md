# Site design tokens (reference)

> Generated by `scripts/build-site-tokens.mjs` from `src/site/design/site.resolver.json` (the W3C DTCG 2025.10 base set `tokens.json` and the theme contexts `tokens.light.json` and `tokens.dark.json`). Do not edit this page: change the JSON and run `node scripts/build-site-tokens.mjs`.

**TL;DR:** 457 tokens for the classic site, the landing and the design library, in three tiers: primitives (`--p-*`, private), semantic roles and scales, and component tokens (`--c-*`). Colour roles have a value in each theme context (emitted as `light-dark()`); fluid sizes grow between a 360 px and a 1280 px viewport (emitted as `clamp()`). The rules for using them are in [the site design system](design-system.md) §2; the live, visual version is the design library at `/design/tokens/`.

## `axes` · Semantic

Fraunces' variable axes. SOFT rounds the serifs (0 sharp to 100 soft); WONK swaps in the leaning, quirky letters. The site's font files have these values built in (scripts/build-site-fonts.py reads them from here); the settings stay for the library's full-axes playground and as documentation.

| Token | Value | Resolves to | Use |
|---|---|---|---|
| `--axes-display` | `'SOFT' 100, 'WONK' 0` |  | Headlines: fully soft, upright |
| `--axes-display-italic` | `'SOFT' 100, 'WONK' 1` |  | Pull quotes and standfirsts: soft, with the wonky italics |
