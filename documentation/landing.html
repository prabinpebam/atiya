Atiya: how this site was built

Every spec, plan, research report and Definition of Done behind Prabin Pebam's portfolio site, its little-planet game, and Atiya, the product it's becoming: a personal site anyone can have, made and published with a desktop app. This is the source of truth for people and for AI agents.

TL;DR

Start with the whole plan: a site on GitHub Pages with public and private pages, the Atiya Studio app that makes and publishes it, Classic as the default navigation, and ways to explore that plug in. The site is an Astro static site with a classic set of pages and a 3D planet you walk around to reach the same content. Then read the seed spec for the why, the planet spec for the game, the game's design system and the site's for the UI rules and the engineering overview for how it's built and shipped.

For AI agents

This site is the source of truth

Read the spec for the area you're changing before you change it, and update it in the same change. The working rules (pinned versions, conventions, validation tiers) are in AGENTS.md at the repository root.

  1. Find the spec

    Use the navigation or search: every feature has a spec and, for larger work, a Definition of Done.

  2. Follow the design system

    Any UI change uses the tokens and components of its design system: the site's for the site, edit mode and the app, and the game's (with its priority lanes) for Little planet.

  3. Keep it true

    When the build differs from the spec, update the spec's "as built" section and its Definition of Done evidence.
