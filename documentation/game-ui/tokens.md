# Design tokens (reference)

> Generated by `scripts/build-tokens.mjs` from `src/design/tokens.json`. Do not edit this page: change the JSON and run `node scripts/build-tokens.mjs`.

The rules for using them are in [the design system](design-system.md) §3. 293 tokens in three tiers: primitives (`--p-*`, only tokens may use them), semantic roles and scales, and component tokens (`--c-*`). Components read colour through the `--surface-*` roles, which `.surface-paper` (the default) and `.surface-wood` set.
