# Asset credits

All 3D geometry in the POC is **original**, built procedurally from three.js primitives (boxes, cones, cylinders, spheres, tori) in `src/game/world/` and `src/game/player/`. No third-party models, textures, fonts, audio, or animations are used.

Fonts are the visitor's system fonts (Segoe UI / system-ui); nothing is loaded from a CDN.
